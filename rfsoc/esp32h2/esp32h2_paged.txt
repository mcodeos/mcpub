2: 产品概述
2: ESP32-H2 是一款低功耗的 MCU 系统级芯片 (SoC)，支持 2.4 GHz 低功耗蓝牙 (Bluetooth® LE) 和 802.15.4 无
2: 线通信。芯片集成了 RISC-V 32 位处理器、低功耗蓝牙基带、802.15.4 基带、RF 模块以及外设。

3: 产品特性
3: 蓝牙
3: 
3:   • 低功耗蓝牙 (Bluetooth LE)：通过 Bluetooth 5.3 认证
3: 
3:   • 蓝牙 mesh
3: 
3:   • Bluetooth LE 长距传输（Coded PHY，125 Kbps 和 500 Kbps）
3: 
3:   • Bluetooth LE 高速传输 (2 Mbps)
3: 
3:   • Bluetooth LE 广播扩展 (Advertising Extensions) 和多广播 (Multiple Advertising Sets)
3: 
3:   • 支持广播设备 (Broadcaster), 扫描设备 (Observer), 中心设备 (Central) 和外围设备 (Peripheral) 同时运行
3: 
3:   • 支持多连接 (Multiple Connections)
3: 
3:   • 功率控制 (LE Power Control)
3: 
3: 
3: 802.15.4
3: 
3:   • 兼容 IEEE 标准 802.15.4-2015
3: 
3:   • 2.4 GHz 频段内支持 250 Kbps 数据速率，OQPSK PHY
3: 
3:   • 支持 Thread 1.4
3: 
3:   • 支持 Zigbee 3.0
3: 
3:   • 支持 Matter
3: 
3:   • 支持其他应用层协议（HomeKit、MQTT 等）
3: 
3: 
3: CPU 和存储
3: 
3:   • RISC-V 32 位单核处理器
3: 
3:   • 时钟频率：最高 96 MHz
3: 
3:   • CoreMark® 得分：
3: 
3:       – 主频 96 MHz：303.38 CoreMark; 3.16 CoreMark/MHz
3: 
3:   • 四级流水线架构
3: 
3:   • 128 KB ROM
3: 
3:   • 320 KB SRAM
3: 
3:   • 4 KB LP 存储器
3: 
3:   • 2 MB 或 4 MB 封装内 flash
3: 
3:   • 16 KB cache
3: 
3:   • 支持 SPI 协议：SPI、Dual SPI、Quad SPI、QPI，可外接 flash 和其他 SPI 设备
3: 
3:   • 支持 flash 在线编程
3:

4: 高级外设接口
4: 
4:  • 19 个可编程 GPIO
4: 
4:     – 3 个 strapping 管脚：GPIO8、GPIO9 和 GPIO25
4: 
4:  • 数字接口：
4: 
4:     – 2 个 SPI 接口用于连接 flash
4: 
4:     – 通用 SPI 接口
4: 
4:     – 2 个 UART
4: 
4:     – 2 个 I2C
4: 
4:     – I2S
4: 
4:     – 红外收发器，2 个发送通道和 2 个接收通道
4: 
4:     – 脉冲计数器
4: 
4:     – LED PWM 控制器，多达 6 个通道
4: 
4:     – USB 串口/JTAG 控制器
4: 
4:     – 电机控制脉宽调制器
4: 
4:     – 通用 DMA 控制器（简称 GDMA），3 个接收通道和 3 个发送通道
4: 
4:     – TWAI® 控制器，兼容 ISO 11898-1（CAN 规范 2.0）
4: 
4:     – SoC 事件任务矩阵
4: 
4:     – 并行 IO 控制器
4: 
4:  • 模拟接口：
4: 
4:     – 12 位模/数转换器，多达 5 个通道
4: 
4:     – 温度传感器
4: 
4:     – 欠压检测器
4: 
4:  • 定时器
4: 
4:     – 2 个 54 位通用定时器
4: 
4:     – 52 位系统定时器
4: 
4:     – 3 个看门狗定时器
4: 
4: 
4: 功耗管理
4: 
4:  • 通过选择时钟频率、占空比、RF 工作模式和单独控制内部器件的电源，实现精准电源控制
4: 
4:  • 针对典型场景设计的不同功耗模式：Active、Modem-sleep、Light-sleep、Deep-sleep
4: 
4:  • Deep-sleep 模式下功耗低至 7 µA
4: 
4:  • Deep-sleep 模式下 LP 存储器仍保持工作
4:

5: 安全机制
5: 
5:  • 安全启动 - 保障固件完整性
5: 
5:  • Flash 加密 - 加密和解密存储器
5: 
5:  • 4096 位 OTP，用户可用的高达 1792 位
5: 
5:  • 加密硬件加速器：
5: 
5:      – AES-128/256 (FIPS PUB 197)
5: 
5:         * ECB/CBC/CFB/OFB/CTR (FIPS PUB 800-38A)
5: 
5:      – SHA 加速器 (FIPS PUB 180-4)
5: 
5:      – RSA 加速器
5: 
5:      – ECC 加速器
5: 
5:      – ECDSA 数字签名外设 (ECDSA_DS)
5: 
5:      – HMAC
5: 
5:      – RSA 数字签名外设 (RSA_DS)
5: 
5:  • 访问权限管理 (APM)
5: 
5:  • 随机数生成器 (RNG)
5: 
5:  • 电源毛刺检测器
5: 
5: 
5: RF 模块
5: 
5:  • 天线开关、射频巴伦 (balun)、功率放大器、低噪声放大器
5: 
5:  • 低功耗蓝牙接收器灵敏度 (125 Kbps) 高达 -106.5 dBm
5: 
5:  • 802.15.4 接收器灵敏度 (250 Kbps) 高达 -102.5 dBm
5: 
5: 
5: 应用
5: 低功耗芯片 ESP32-H2 专为物联网 (IoT) 设备而设计，应用领域包括：
5: 
5:  • 智能家居                                       • Matter 解决方案
5: 
5:  • 工业自动化
5:                                               • 服务机器人
5:  • 医疗保健
5:                                               • 通用低功耗 IoT 传感器集线器
5:  • 消费电子产品
5: 
5:  • 智慧农业                                       • 通用低功耗 IoT 数据记录器

13: 2.2 管脚概述
13: ESP32-H2 芯片集成了多个需要与外界通讯的外设。由于芯片封装尺寸小、管脚数量有限，传送所有输入输出信
13: 号的唯一方法是管脚多路复用。管脚多路复用由软件可编程的寄存器控制（详见 《ESP32-H2 技术参考手册》
13: > 章节 IO MUX 和 GPIO 交换矩阵）。
13: 
13: 总体而言，ESP32-H2 芯片的管脚可分为以下几类：
13: 
13:     • IO 管脚，具有以下预设功能：
13: 
13:          – 每个 IO 管脚都预设了 IO MUX 功能 – 见表 2-3 IO MUX 管脚功能
13: 
13:          – 部分 IO 管脚预设了模拟功能 – 见表 2-5 模拟功能
13: 
13:      预设功能即每个 IO 管脚直接连接至一组特定的片上组件信号。运行时，可通过映射寄存器配置连接管脚
13:      的组件信号。
13: 
13:     • 模拟管脚，专用于模拟功能 – 见表 2-6 模拟管脚
13: 
13:     • 电源管脚，为芯片组件和非电源管脚供电 – 见表 2-7 电源管脚
13: 
13: 
13: 根据是否可在 Deep-sleep/Light-sleep 模式下工作，ESP32-H2 芯片的 IO 管脚也可分为：
13: 
13:     • 数字管脚 (GPIO0 ~ GPIO5, GPIO22 ~ GPIO27)：不可在 Deep-sleep 模式下工作。可在 Light-sleep 模式下
13:      工作但需要确保 XPD TOP 控制的电源域不掉电。更多信息见《ESP32-H2 技术参考手册》 > 章节 低功耗
13:      管理。
13: 
13:     • LP 管脚 (GPIO8 ~ GPIO14)：可在芯片任意模式工作。
13:

15: 2.3 IO 管脚
15: 2.3.1 IO MUX 功能
15: IO MUX 能让一个输入/输出管脚连接多个输入/输出信号。ESP32-H2 的每个 IO 管脚可在表 2-3 IO MUX 管脚功
15: 能 列出的五个信号（IO MUX 功能，即 F0-F4）中选择，连接任意一个。
15: 
15: 五个信号中：
15: 
15:     • 部分源自 GPIO 交换矩阵（GPIO0、GPIO1 等）
15:                                   。GPIO 交换矩阵包含内部信号传输线路，用于映射信号，能令
15:         管脚连接几乎任一外设信号。这种映射虽然灵活，但可能影响传输信号的速度，造成延迟。如何通过 GPIO
15:         交换矩阵连接外设信号，详见 《ESP32-H2 技术参考手册》 > 章节 IO MUX 和 GPIO 交换矩阵。
15: 
15:     • 部分直接源自特定外设（U0TXD、MTCK 等）
15:                              ，包括 UART0、JTAG 和 SPI2 - 详见表 2-2 通过 IO MUX 连接
15:         的外设信号。

18: 2.3.3 GPIO 限制
18: ESP32-H2 的所有 IO 管脚都有 GPIO 功能。这些 IO 管脚是多功能管脚，可以根据需求配置不同的功能，也有一
18: 些使用限制，需要特别注意。
18: 
18: 本章节的表格中，部分管脚功能有 高亮 标记。推荐优先使用没有高亮的 GPIO 管脚。如需更多管脚，请谨慎选
18: 择高亮的 GPIO 管脚，避免与重要功能冲突。
18: 
18: 高亮的 IO 管脚有以下重要功能之一：
18: 
18:     • Strapping 管脚 – 启动时逻辑电平需为特定值。详见章节 3 启动配置项。
18: 
18:     • USB_D+/- – 默认情况下连接 USB 串口/JTAG 控制器。此类管脚需重新配置，方可用作 GPIO。
18: 
18:     • JTAG 接口 – 通常用于调试功能。详见表 2-2 通过 IO MUX 连接的外设信号。要释放这类管脚，可用 USB
18:      串口/JTAG 控制器的 USB_D+/- 功能代替。详见章节 3.3 JTAG 信号源控制。
18: 
18:     • UART 接口 – 通常用于调试功能。详见表 2-2 通过 IO MUX 连接的外设信号。

25: 4.1.1.1 ESP-RISC-V CPU
25: 
25: ESP-RISC-V CPU 是一款基于 RISC-V 指令集架构 (ISA) 的 32 位内核，包括基本整数 (I)、乘法/除法 (M)、原子
25: (A) 和压缩 (C) 标准扩展。
25: 
25: 特性
25: 
25:   • 四级流水线，时钟工作频率高达 96 MHz
25: 
25:   • RV32IMAC ISA (指令集架构)
25: 
25:   • 符合 RISC-V 指令集手册 v2.2 第一卷“非特权架构”(RISC-V Instruction Set Manual Volume I: Unprivileged
25:       ISA, Version 2.2) 和 RISC-V 指令集手册 v1.10 第二卷“特权架构”(RISC-V Instruction Set Manual, Volume
25:       II: Privileged Architecture, Version 1.10)
25: 
25:   • 通过 IRAM/DRAM 接口零等待周期访问片上 SRAM 和 cache 中的程序和数据
25: 
25:   • 具有静态分支预测功能的分支目标缓冲区 (BTB)
25: 
25:   • 支持用户模式 (user mode) 以及中断委托
25: 
25:   • 中断控制器 (INTC) 具有多达 28 个外部向量中断，适用于机器模式 (machine mode) 和用户模式，可配置
25:       16 个优先级和阈值级别
25: 
25:   • 专用于机器模式和用户模式的核心本地中断 (CLINT)
25: 
25:   • 调试模块 (DM) 符合 RISC-V 外部调试支持规范 (RISC-V External Debug Support) v0.13，支持通过行业标
25:       准的 JTAG/USB 端口连接外部调试器
25: 
25:   • 支持指令追踪，详见章节 4.1.1.2 RISC-V 追踪编码器
25: 
25:   • 调试器通过系统总线 (SBA) 直接访问存储器和外设
25: 
25:   • 硬件触发器符合 RISC-V 调试规范 v0.13，具有多达 4 个断点/观察点
25: 
25:   • 物理存储器保护 (PMP) 和物理存储器属性 (PMA)，最多可配置 16 个区域
25: 
25:   • 32 位 AHB 系统总线，用于访问外设
25: 
25:   • 可配置的核心性能指标事件
25: 
25: 更多信息，请参考 《ESP32-H2 技术参考手册》 > 章节 ESP-RISC-V CPU。

26: 4.1.1.2 RISC-V 追踪编码器
26: 
26: ESP32-H2 芯片中的 RISC-V 追踪编码器提供了一种从 CPU 执行过程中捕获详细追踪信息的方法，以便对系统
26: 进行更深入的分析和优化。它连接到 CPU 的指令追踪接口，并将信息压缩成较小的数据包，然后存储在内部
26: SRAM 中。
26: 
26: 特性
26: 
26:   • 兼容 RISC-V 追踪规范 v1.0 (RISC-V Processor Trace 1.0)
26: 
26:   • 支持任意地址范围用作追踪存储器
26: 
26:   • 具有两种同步模式：
26: 
26:       – 同步计数器按包计数
26: 
26:       – 同步计数器按周期计数
26: 
26:   • 支持丢包状态标识
26: 
26:   • 支持丢包后自动重启
26: 
26:   • 写追踪存储器时支持循环和非循环模式
26: 
26:   • 具有 128 × 8 位 FIFO，用于缓存数据包
26: 
26: 更多信息，请参考 《ESP32-H2 技术参考手册》 > 章节 RISC-V 追踪编码器 (TRACE)。

26: 
26: 4.1.1.3 GDMA 控制器
26: 
26: GDMA 控制器是通用的直接内存访问控制器，可以在无需 CPU 干预的情况下完成外设与存储器之间及存储器与
26: 存储器之间的数据传输。GDMA 具有六个独立通道，其中三个用于发送，三个用于接收。这些通道由具有 GDMA
26: 功能的外设共享，包括 SPI2、UHCI (UART0/UART1) 、I2S、AES、SHA、ADC 和 PARLIO。
26: 
26: 特性
26: 
26:   • AHB 总线架构
26: 
26:   • 可编程的数据传输长度（以字节为单位）
26: 
26:   • 链表描述符，用于高效的数据传输管理
26: 
26:   • 在访问内部 RAM 时进行 INCR burst 传输，以提高性能
26: 
26:   • 访问高达 324 KB 的内部 RAM 地址空间
26: 
26:   • 软件可选择请求服务的外设
26: 
26:   • 用于管理带宽的固定优先级和轮询通道仲裁方案
26: 
26:   • 支持事件任务矩阵
26: 
26: 更多信息，请参考 《ESP32-H2 技术参考手册》 > 章节 GDMA 控制器 (DMA)。

31: 4.1.3.6 电源管理单元
31: 
31: ESP32-H2 具有先进的电源管理单元 (PMU) ，可以灵活地为芯片的不同电源域供电，实现芯片性能、功耗和唤
31: 醒延迟之间的最佳平衡。
31: 
31: 配置 PMU 的程序较为复杂。为针对典型场景简化电源管理，ESP32-H2 具有以下预设功耗模式，可给不同电源
31: 域组合供电：
31: 
31:    • Active 模式 – CPU、RF 电路和所有外设均上电。芯片可以处理数据、接收、发射和侦听信号。

31:    • Modem-sleep 模式 – CPU 上电，可降低时钟频率。RF 电路在需要时间歇性开启，因此无线可保持连接。

31:      唤醒，包括 Modem、RTC 定时器或外部中断。无线可保持连接。部分数字外设可选择关闭。
31: 
31:    • Deep-sleep 模式 – 仅 LP 系统上电。无线连接数据存储在 LP 存储器中。
31:

47: 4.3.1.1 2.4 GHz 接收器
47: 
47: 2.4 GHz 接收器将 2.4 GHz 射频信号解调为基带信号，并用两个高精度 ADC 将基带信号转为数字信号。为了适
47: 应不同的信道情况，ESP32-H2 集成了 RF 滤波器、自动增益控制 (AGC)、DC 偏移补偿电路和基带滤波器。
47: 
47: 
47: 4.3.1.2 2.4 GHz 发射器
47: 
47: 2.4 GHz 发射器将基带信号调制为 2.4 GHz 射频信号，使用互补金属氧化物半导体 (CMOS) 功率放大器驱动天
47: 线。
47: 
47: 为了抵消射频接收器的瑕疵，ESP32-H2 还另增了校准措施，例如：
47: 
47:   • 载波泄露消除
47: 
47:   • I/Q 振幅/相位匹配
47: 
47: 这些内置校准措施缩短了产品的测试时间，并且不再需要测试设备。
47: 
47: 
47: 4.3.1.3 时钟生成器
47: 
47: 时钟生成器为接收器和发射器生成 2.4 GHz 时钟信号，所有部件均集成于芯片上，包括电感、变容二极管、环
47: 路滤波器、线性稳压器和分频器。
47: 
47: 时钟生成器带有内置校准电路和自测电路。运用自主知识产权的优化算法，对时钟的相位和相位噪声进行优化
47: 处理，使接收器和发射器都有最好的性能表现。
