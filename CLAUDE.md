# mcpub rules

- Language rule: **everything** in this repo must be written in **English** — docs, descriptions, string fields, manifests, READMEs, and code comments alike — because packages are submitted externally.
- No exceptions: Chinese is not allowed anywhere in `mcpub/` file contents, including comments.

## Entry `.mc` / `pack.toml` header (mandatory)

Every entry `.mc` **opens with** the standard provenance/disclaimer header, in
the file's own comment style (`#` or `//`) — and nothing else: no per-file
copyright or license lines (licensing terms live in the repo root `LICENSE`).
Every `pack.toml` opens with the same block (TOML-comment style), followed by
a blank line and `[package]`:

```text
Generated by MCode Bench(TM). Transcribed from the manufacturer's public
datasheet. All datasheets, trademarks and other referenced materials are
the property of their respective third-party owners. Provided AS IS,
without warranty of any kind; verify against the original manufacturer
documentation before production use.
```

These conventions are **mcpub-local** (this file + `check.sh`); they are
deliberately not canonized in `mcd`.

## Enforcement

`check.sh` is the corpus gate (run standalone or via the pre-commit hook,
which chains it before `bump.sh --staged`). It fails on: CJK text in
authored files (vendor datasheet dumps exempt), missing provenance headers,
missing datasheet source url, stale versioned artifact names in READMEs.

## Datasheet source link (mandatory)

Every `pack.toml` carries a linked `[[attachments]]` block pointing at the
original datasheet PDF download (`kind = "datasheet"`, `name = "<Vendor> <Part>
datasheet (original PDF download)"`). The URL must be verified (vendor-domain
search hit or curl 2xx/3xx); when the original source cannot be identified,
keep `url = ""` as an explicit placeholder — never guess a URL.
